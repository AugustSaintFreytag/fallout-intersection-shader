# Experimental Intersections

Experimental shaders and NVSE companion plugin for New Vegas that introduces visual blending between terrain and statics. Effectively smooths out transitions between terrain and placed landscape features and objects to remove hard seams inbetween.

Inspired by the Skyrim Community Shader project.

Note: Currently requires a fork of FNV Depth Resolve (not yet released).
